# Flood Monitoring Dashboard (New Orleans)

## Overview
An interactive web dashboard developed as part of the Esri MOOC program ("Make an Impact with Modern Geo Apps") to visualize flood levels, weather events, and infrastructure status in the New Orleans-Metairie area.

## Features & Capabilities
- **Dashboard Configuration:** Designed and structured interactive widgets, gauges, and serial charts using pre-configured map layers.
- **Stream Observation:** Configured panels to display NOAA stream gauge monitoring data and river metrics.
- **Weather Alert System:** Integrated visual indicators for active weather events and warnings.
- **Infrastructure Metrics:** Displayed operational status and metrics for pump station backup power units.

## Technical Stack & Tools
- ArcGIS Dashboards

## Deliverables & Results
- Configured Interactive Web Dashboard Layout
- Integrated Spatial Layers and Data Widgets
